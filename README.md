# vectura-wanted

Public field list for the Vectura research project — the specific prices a headless
fetch could not reach, written to be actioned from a phone in a shop.

Answers are kept in the browser's own storage on the device that typed them, and
exported by copy. **Nothing is sent anywhere**: the page is static, has no backend,
and stores nothing server-side. Everything on it — brands, models, retail prices —
is public retail information.

Served at https://vectura-wanted.sideri.io via GitHub Pages.
