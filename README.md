# vectura-wanted

Two static pages for the Vectura research project.

- **`/`** — the desk: every open decision and every section only Rahut can write,
  generated from the project's state. Saves file back as labelled GitHub issues.
- **`/ledger`** — the case ledger: one row per brand entering one market, the same
  product priced on both sides of the border, and the chart that is the point of
  the whole exercise.

Both are generated by `tools/build-desk.py` in the private research repo and
published by `tools/publish-desk.sh`, which runs after every pipeline command and
pushes only when a page actually changed.

No backend, no analytics, no account. Everything here is public retail
information — brands, models, shelf prices — plus the reasoning applied to it.

Served at https://vectura-wanted.sideri.io via GitHub Pages.
